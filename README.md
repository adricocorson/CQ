# CaptiveQuant

Landing page for CaptiveQuant, a crypto trading class on Discord.

Live: https://adricocorson.github.io/CQ/

## Files

- `index.html`: the whole page (React from a CDN, no build step)
- `logo.webp`: the logo, used by the 3D hero and the dot logo
- `panel-1.webp`, `panel-2.webp`, `panel-3.webp`: the glass renders for the channel cards
- `icon.png`: the browser-tab and home-screen icon
- `vercel.json`: settings if the site is ever deployed on Vercel

## Editing

Prices, the voucher and its end date, the Discord link and the member count are near the top of the script in `index.html`
(`KELAS`, `PAKET`, `ANGGOTA`, `DISCORD`). The first screen is also written out in plain HTML near the top of the body,
so keep its headline and member count in step with the hero.
